# 视觉参考

阶段 2（分镜）和阶段 3（开发）用到的细节。表里的具体元素都是举例，按当前项目的风格和参考图取舍。

## 1. 先定视觉系统

阶段 2 的第一步，写进分镜文档开头，一页以内：

- **色板**：底色、主色、强调色、文字色。文字和底色的对比度不低于 4.5:1，压在图片上的字加底板或阴影。
- **字体**：最多两款（标题一款、正文一款），列出每款要用的字重，每个字重都要有字体文件。
- **字号阶梯**：3～4 级。竖屏 1080×1920 的参考起点：正文不小于 48 px，标题 96 px 起；横屏 1920×1080：正文不小于 40 px。手机上看，比电脑上觉得合适的再大一号。
- **形状与质感**：线宽、圆角、阴影、纹理（纸纹、颗粒、噪点）各定一套参数，全片共用。
- **缓动**：全片 2～3 条缓动曲线（入场、强调、退场），不要每一镜各写一条。
- **动效词汇**：从下一节的表里选 4～6 个，全片反复使用，观众会把它们当成这支片子的语言。

每一镜的视觉隐喻在这套系统里变化：换构图、换隐喻对象、换运镜，但不换色板、字体和动效语言。

## 2. 风格 → 动效词汇

| 风格 | 适合 | 慎用 |
|---|---|---|
| 手账 / 拼贴 | 贴纸弹入、胶带撕拉、印章盖下、手写描边、便签翻折、纸张轻微抖动 | 霓虹光效、玻璃拟态、3D 翻转 |
| 语录 / 金句 | 字重或字距变化、逐字浮现、光线扫过、大留白里的慢推、黑场呼吸 | 星芒、贴纸、弹跳、频繁抖动 |
| 信息图 / 知识卡片 | 数字滚动、柱条和进度生长、描边高亮、箭头路径、分屏对比、局部放大镜 | 大面积抖动、装饰粒子 |
| 海报 / 杂志 | 大字切入、版面错位、色块推移、遮罩揭示 | 卡通弹跳、手绘描边 |

“光环星芒”一类装饰性反馈放在手账里合适，放到极简语录或信息图里容易显得廉价，按风格换成字重变化或描边高亮。

## 3. 音乐能量 → 画面密度

按阶段 1 报告里的“级别”和“律动”两列分配：

| 级别 / 律动 | 画面 |
|---|---|
| 低 / 疏 | 一个焦点，慢推或漂移，元素少、留白多；仍然保持微动 |
| 中 | 按拍揭示、按小节换镜 |
| 高 / 密 | 视觉连击、分屏对比、重拍冲击；同一时刻仍然只有一个主焦点 |

重拍冲击要限量：每个乐句（通常 4 或 8 小节）最多一两次强冲击；爆点前留 1～2 拍“收”的动作（缩小、停顿、变暗），冲击才显得重。全片都在冲击，爆点就显不出来。

冲击动效的参数参考（30 fps）：瞬推回弹 1.00 → 1.04～1.06 → 1.00，6～8 帧；微震位移 ≤ 画面宽度的 0.5%，4～6 帧内衰减到 0，只作用在容器或背景上，正在阅读的文字不抖；高亮或光环 8～12 帧淡出。

## 4. 安全区

### 平台界面遮挡

- **竖屏短视频**（抖音、视频号、小红书、TikTok）：核心文案和主体默认避开上 10%、下 25%、左右各 6%，画面高度 45% 以下的右侧按钮列再多避开 15%。这是按常见界面估的日常默认值，各平台不同，正式发布前用目标平台的安全区模板核对。要更稳妥（比如投放广告）时用更严的数值：[Shotstack 实测的 TikTok 官方信息流模板](https://shotstack.io/learn/vertical-video-safe-zones/)在 1080×1920 上留出顶部 240 px、底部 660 px、两侧 120 px，840 px 以下右侧 300 px。
- **横屏**（B 站、YouTube）：四周各留 5%。

装饰元素可以越过安全区，核心文案和主体图形不行。

### 运镜时的计算

每个焦点（正在呈现的文案块或主体图形）在画布坐标里有一个框。镜头变换后它在屏幕上的位置这样算：CSS 里 `transform: translate(tx, ty) scale(s)`、`transform-origin: ox oy` 对应 `屏幕点 = 原点 + 平移 + s × (画布点 - 原点)`。

```ts
type Box = {x: number; y: number; w: number; h: number};
type Cam = {scale: number; tx: number; ty: number; ox: number; oy: number};

export const toScreen = (b: Box, c: Cam): Box => ({
  x: c.ox + c.tx + c.scale * (b.x - c.ox),
  y: c.oy + c.ty + c.scale * (b.y - c.oy),
  w: b.w * c.scale,
  h: b.h * c.scale,
});

export const inside = (b: Box, safe: Box) =>
  b.x >= safe.x && b.y >= safe.y && b.x + b.w <= safe.x + safe.w && b.y + b.h <= safe.y + safe.h;
```

- 焦点从出场第一帧到停留结束的每一帧都要满足 `inside(toScreen(焦点, 镜头), 安全区)`。开发时可以在 Studio 里加一个只在预览时显示的调试层，画出安全区和焦点框。
- 装饰元素（活页线圈、边框、胶带等）和焦点框有重叠时，要么移开装饰，要么让焦点避开它。
- 大幅特写时，不在焦点里的大标题和边缘元素要淡出、移出画外，或者放在不跟镜头走的独立图层上，不能被画框拦腰切半。
- 位图（纸纹、照片、参考图）的像素要够：素材宽度 ≥ 它在画面上显示的宽度 × 最大放大倍数。例如在 1080 宽的画面里铺满、最多推到 2.5 倍的纸纹，需要 2700 px 宽。文字和 SVG 不受影响。

## 5. 中文排版

- 在分镜里就把每一行断好，按语义断：词组不拆开，不在“的、了、和”前面断。代码里用 `\n` 或数组逐行渲染，不依赖自动换行。
- 行首不放 `，。、；：？！）」』》…—` 这类标点；行尾不放 `（「『《` 这类开括号和开引号。
- 不留单字成行。一行最多 16 个字；竖屏大字号通常 8～12 个字一行更好读。
- 全角标点；中文和英文、数字之间要不要空格，和项目现有风格保持一致。
- 会跳动的数字用等宽数字：`font-variant-numeric: tabular-nums`（字体要支持），或者选数字本身等宽的字体，否则数字一变整行左右晃。
- `check_glyphs.py` 会检查手动断行后的行首标点、行尾开括号、单字成行和超长行。

## 6. Remotion 写法

### 分步揭示：触发前进度严格为 0

```ts
const clamp = {extrapolateLeft: 'clamp', extrapolateRight: 'clamp'} as const;
const p = interpolate(frame, [trigger, trigger + 18], [0, 1], clamp);
const s = frame < trigger ? 0 : spring({frame: frame - trigger, fps, config: {damping: 200}});
```

- `interpolate` 两端都要 clamp，否则触发前会出现负值或提前露出。
- 路径描边：`strokeDasharray = 路径长度`、`strokeDashoffset = 路径长度 × (1 - p)`，或者用 `@remotion/paths` 的 `evolvePath(p, d)`。用圆头描边（`strokeLinecap="round"`）时，进度为 0 也会露出一个圆点，要加 `opacity={p > 0 ? 1 : 0}`。
- 印章、结果、答案这类“揭晓”元素，触发前不挂载（放进 `<Sequence from={trigger}>`）或者透明度为 0。
- 在 Studio 里检查每个触发点的前一帧，确认什么都没露出来。

### 计时器和进度数字

数字和动效用同一个进度值，逐帧变化：

```ts
const p = interpolate(frame, [start, end], [0, 1], clamp);
const value = Math.round(p * target);   // 显示的数字
const width = p * barWidth;             // 同一个 p 驱动进度条
```

### 字体

```ts
import {loadFont} from '@remotion/fonts';
import {staticFile} from 'remotion';

loadFont({family: 'Title', url: staticFile('<合成名>/fonts/Title-Bold.woff2'), weight: '700'});
loadFont({family: 'Body', url: staticFile('<合成名>/fonts/Body-Regular.woff2'), weight: '400'});
```

`loadFont()`（4.0.165 起）会自动等字体加载完再渲染。没有 `@remotion/fonts` 的老项目用 `@font-face` 加 `delayRender()` / `continueRender()`。不要用远程字体：渲染依赖网络，网络慢或断开时会回退。

### 性能

- 纸纹、颗粒、噪点、复杂的 SVG 滤镜（`feTurbulence`、大半径模糊）预先生成静态图，按上面的位图分辨率要求准备，用 `<Img src={staticFile(...)} />` 引用。
- 需要动态颗粒时，预先生成 3～4 张，按帧轮换：`const k = Math.floor(frame / 2) % 4`。
- 大面积的 `filter: blur()`、`backdrop-filter` 和多层大阴影每帧都要重新计算，能预渲染就预渲染。
